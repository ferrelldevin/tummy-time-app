# Security

## Reporting a problem
If you find a security or privacy problem, do not open a public issue. Tell the project lead, Devin Ferrell, directly, or use GitHub's "Report a vulnerability" button on this repo's Security tab.

Include what you did, what you saw, and what you expected. Do not include real personal data in the report.

## What we promise
- We acknowledge a report within 3 working days.
- We fix high-severity problems before any other work merges.
