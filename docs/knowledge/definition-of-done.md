# Tummy Time: definition of done
Updated: Nov 9, 2026. Built on the lab work standard. A piece of work is done only when every line in its section is true.

## Every feature
- Works for the real user, checked by using it on a phone, not by reading the code.
- Tests cover the parts that would hurt if they broke. The "when to call" card and the corrected-age math always have their own tests.
- Passes an automatic accessibility scan (axe or Lighthouse) and a manual VoiceOver and TalkBack pass. Target: WCAG 2.1 AA.
- Works on iPhone Safari and Android Chrome, older phones included.
- Uses only made-up sample data.
- Stores no field that isn't in the data map.
- PR says what changed and why. Credit for any library, asset or source is in the PR and README.
- No AI filler: no placeholder text, unused code, generic comments or unasked features.
- Client has seen it at a demo and accepted it.

## Every lesson
- Follows the lesson template and the content style guide.
- Reading level 6th to 8th grade.
- Video captioned, with a transcript.
- Clinician sign-off recorded with a name and date.

## Every drop or release
- Someone new can run it from the README alone.
- Decision log and open questions are updated.
- Consent and survey screens stay switched off until the IRB approves.

## Every document for the client or Dr. Gupta
- Bottom line first.
- Unconfirmed facts are marked unconfirmed.
- Sources named; no copied source text.
- Footer: "Selection and arrangement by Devin Ferrell, produced with AI assistance."
